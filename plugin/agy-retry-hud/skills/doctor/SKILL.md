---
name: doctor
description: "Run a complete agy-retry-hud health check covering plugin wiring, skills, config, daemon, hooks, statusline, and retry runtime."
---

Run `agy-retryctl doctor --json` and report failures precisely.
If setup assets are incomplete, run `agy-retryctl setup repair --json` and then repeat doctor.
Do not send a model prompt merely to test retry behavior.

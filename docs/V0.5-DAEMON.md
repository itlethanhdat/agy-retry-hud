# v0.5 Embedded Daemon Architecture

- Singleton per default user state root.
- PID ownership + heartbeat runtime state.
- Auto activation through statusline/PreInvocation/Stop callbacks.
- Adaptive scheduler scan.
- One shared dispatch semaphore (`maxConcurrentDispatch`, default 1).
- Retry deadlines continue while the TUI is idle.
- Handoff PREPARING/PENDING/ROLLOVER_ARMED states are picked up by the daemon.
- `hud hide` only removes visual output; `hud off` disables daemon/retry/handoff.

## Runtime paths

The daemon lives next to the native state root under a `daemon/` directory and stores `daemon.json` plus `runtime.json` atomically.

## TUI redraw limitation

The daemon cannot safely force a native AGY TUI repaint through the public plugin API. Runtime scheduling remains live independently; the visible statusline refreshes on the next AGY redraw.
